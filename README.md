# IT141 – CCNA: Switching, Routing, and Wireless Essentials

Student-facing session review pages for IT141, the second course in a three-course CCNA series. Each session has a lecture recap, flashcards, sample quizzes, worked examples, and a glossary. The OSI Company story world and lab network from CCNA 1 carry straight on into this course.

- **Previous course:** [CCNA 1: Introduction to Networks (IT131)](https://kevinsays.github.io/131/)
- **Next course:** CCNA 3: Enterprise Networking, Security, and Automation (IT231). In progress.

**Site:** start at `index.html`. It links out to every session and reference page. Sessions are added as the term goes on.

Built with plain HTML/CSS/JS, no build step. The shared look lives in `assets/theme.css` and `assets/site.js`. To preview locally, just open `index.html` in a browser, or serve the folder with any static file server.

## Curriculum version

These pages follow **Cisco NetAcad CCNAv7: Switching, Routing, and Wireless Essentials** (v7.02). As soon as CCNAv8 material is available, I'll be moving the pages over to version 8. Until then, module numbers, topics and terms match v7. All lab work is designed for Cisco Packet Tracer.

This site started as my own course pages. You're welcome to use it in your own classes. It follows the NetAcad module order, and the license below lets you adapt it. Be sure to credit me and my page so that others who want to do so can also find this material.

- **Use it as-is:** send students the link to the site, or to a single session page.
